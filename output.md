## What changed

### Core sim
- `src/core/game.hpp`: new `PoleKind` enum (POLE_PLAIN/SEVER/BREAK/CRACK);
  `Pole` gains `+hp` (u8), `+broken` (u8), `+kind` (i8) — RAM +3 B.
- `src/core/projectiles.hpp`:
  - hardcoded PROGMEM `POLE_DEFS[4]` (MONSTER_DEFS precedent; no JSON) +
    `poleDef*` accessors over `mhPgmRead*`. Fields: rect w/h, zone box
    (zox/zoy/zw/zh), pool, breakTypes mask, brokenW/H, brokenFlags.
    PLAIN 20x36 no zone; SEVER zone 20x16@0,0 pool 60 SLASH, brokenFlags bit0
    (crit lost), rect 20x36; BREAK zone 8x12@20,8 pool 40 BLUNT, rect 28->20;
    CRACK zone 20x10@0,18 pool 30 SHOT.
  - `initWorld` resets kind 0/hp 0/broken 0; new `initPoleKind(g, kind)`
    installs a variant (rect/pool/broken) and refreshes the train target.
  - `damagePole` now returns the applied total; SEVER loses the head crit x1.4
    once broken (brokenFlags bit0).
  - `poleOnHit` does point-in-zone (half-open, facing-free) and drains the pool
    only when `playerPhys(g) & breakTypes`; pool 0 -> broken + `poleBreakBurst`
    (3 fxspark effects, crit=false so the audio critSpark scan is not tripped) +
    freeze 6 + broken art (render reads `pole.broken`) + target rect refresh
    (BREAK 28->20).
  - projectile train hits now route through `poleOnHit` so shots can crack.
- `src/core/world.hpp`: `withWeapon`/`resetHunt` preserve `pole.kind` in train
  (mirrors the mock).
- `src/menu_state.hpp`: `MENU_TARGET_COUNT 8`; `menuMode` = target >= 4;
  `menuMonsterKind` unchanged for 0..3; new `menuPoleKind` (target-4);
  `menuStart` calls `initPoleKind` after `newGame` (newGame signature and
  default kind 0 unchanged -> parity scenes untouched).
- `src/audio.hpp`: `CUE_BREAK` (+ enum, cue table entry 12 rows, snapshot
  field `poleBroken`); priority break > defense > crit > hit. FITS (see size).

- `src/render.hpp`: `poleSheet(kind)` + `poleSheetFrame(kind, broken, flash)`;
  `drawPole` selects the variant sheet and broken/flash frame.
- `images/blocks/fxpole_{sever,break,crack}_*.png`, `images/menu/mh_menu_*`
  regenerated by `make gen` (never hand-edited).
